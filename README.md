### How to run the Website

1. Download the ZIP file and extract the folder.
2. Open the extracted folder in your IDE.
3. Ensure that **all required files, codes, and folders** are included.
4. Locate and open dashboard.html.
5. Start Live Server in your IDE.
6. Open the website through Live Server.
7. Explore the website.


## What to do in the website

### Goals Tab

1. Click Add New Goal
2. Enter details
3. Save goal
4. (Check dashboard tab to see your goal)
5. Edit goal by clicking pencil/paper icon
6. Complete goal by clicking on checkmark
7. Delete goal by clicking on trash icon and confirming

### Projects Tab

1. Click on Add New Project
2. Enter Details
3. Enter Sub tasks under the project by entering details and clicking "add"
4. Save project
5. (Check dashboard to see your project)
6. Edit project by clicking pencil/paper icon
7. Tick on your finished tasks in the action items
8. Mark the project as completed by editing
9. Delete the project by clicking the trash icon and confirming

### Tasks Tab

1. Click on Add New Task
2. Select your category and enter details
3. (Check the dashboard to see your schedule, deadline, today task)
4. (Try to enter multiple schedule for today to see time progress, enter time before current time, enter time less than 1 hr before schedule, enter time hours after current time)
5. (Try to enter different deadlines after current schedule.) (Feature to follow: past deadlines would not show in the dashboard - fututre feature will include past deadlines alert)
6. (Enter multiple today tasks, interact either on tasks tab or dashboard)
7. Click on the pencil icon to edit tasks
8. Click on the trash icon to delete task and confirm

### Notes Tab

1. Click on Create Note
2. Enter details in the field
3. Click on save note
4. Click on eye icon to view the notes
5. Click on the pencil icon to edit or delete
6. Click on delete note button and confirm to delete note

### Dashboard Tab

1. Once you have Goals, Projects, and Tasks, Go to dashboard
2. Check the dashboard to show summary of your to do lists
3. Click on the box icon and confirm on todays schedule to mark a schedule as finished
4. Tick on the todays tasks to indicate finished task
5. Create a sticky note for a quick reminder or for positive quotes (Click on add new)
6. Edit or delete the sticky note by clicking the ... icon

### Sidebar

1. Collapse or expand sidebar by using the arrow icon on the upper part of the side bar
2. Toggle dark mode by clicking dark mode slider at the bottom of the side bar
3. Click on tabs to switch tabs
4. (Future feature: Click on the name to go to profile, (Not available yet))
