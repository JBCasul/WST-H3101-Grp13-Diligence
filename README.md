### How to run the Website

1. Download the ZIP file and extract the folder.
2. Open the extracted folder in your IDE.
3. Ensure that **all required files, codes, and folders** are included.
4. Locate and open dashboard.html.
5. Start Live Server in your IDE.
6. Open the website through Live Server.
7. Explore the website.


### What to do in the website

1. Create your goals / tasks / projects / notes / sticky notes
2. Ensure that the dates are after current date for upcoming deadlines and current date for today's schedule.
3. Check the dashboard to see your tasks. (Create multiple schedule to see cascading schedule and time left, create multiple deadlines to see deadline differences)
4. Interact with dashboard for schedule, todays task, and sticky notes. 
5. Click on the specific tab if you want to modify your tasks, (E.g. Complete a task under project, change the progress bar for your goal, edit task names, edit your notes)
